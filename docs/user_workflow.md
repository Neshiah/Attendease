# User Workflow

## Student

1. Login with student ID and password.
2. View dashboard, events, points, notifications, and profile.
3. Open an event and scan its QR code during the allowed event time.
4. Submit one feedback form after attendance is recorded.
5. Earn event points after feedback submission.
6. Redeem points for printing, using the configured conversion rate.
7. Track redemption history and point transactions.

## Admin / OSA Staff

1. Login using an admin account.
2. Manage students, users, events, point adjustments, and printing requests.
3. Generate QR codes for events.
4. Review attendance, feedback, points, and printing reports.

## Organizer / Faculty

1. View assigned events.
2. Monitor attendance records.
3. Review feedback results.
4. Export attendance and feedback reports.

## Printing Staff

1. Search or open a student record.
2. Verify available points and pending redemption requests.
3. Approve or reject a request.
4. Points are deducted only when the request is approved.
5. Mark approved redemptions as completed after printing.
